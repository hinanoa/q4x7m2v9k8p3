# Anti-generic design rules

Avoid these defaults unless the product genuinely calls for them:

- A centered gradient hero with a glowing orb, generic dashboard mockup, and three equal feature cards underneath.
- Excessive glassmorphism, neon gradients, purple-blue ambient glows, and decorative blur with no product meaning.
- Every container rendered as a floating rounded card with the same radius, shadow, and padding.
- A pill-shaped element for every label, control, status, and navigation item.
- Oversized headings whose only job is to fill space while the actual product information stays vague.
- Generic startup copy such as “supercharge”, “unlock”, “reimagine”, or “all-in-one” when concrete language is available.
- Random icon grids and feature mosaics that communicate no priority.
- Fake complexity: charts, tables, code blocks, or metrics inserted only to make the product look sophisticated.
- Symmetry everywhere. Use asymmetry, editorial alignment, density changes, or anchored whitespace when they improve hierarchy.
- Motion applied to everything. Animate state changes, spatial relationships, and meaningful transitions instead.

Prefer:

- A page structure that follows the content and user journey.
- One or two strong visual ideas carried consistently through the screen.
- Fewer, better surfaces with clear relationships between them.
- Product-specific interaction details and states.
- Real copy and real examples whenever possible.
- Intentional contrast between dense and quiet areas.
