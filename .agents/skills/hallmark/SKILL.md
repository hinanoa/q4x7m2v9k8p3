# Hallmark

Use this skill to resist the common visual defaults of AI-generated interfaces. The goal is not novelty for its own sake; it is intentional design with a clear point of view.

Read `references/anti-generic.md` before substantial UI work. Read `references/review-gates.md` before finalizing a screen.

## Working method

1. Identify the product's actual job, audience, content density, and interaction model.
2. Pick one coherent visual register instead of mixing unrelated trends.
3. Establish hierarchy through scale, rhythm, alignment, contrast, and content order before adding decoration.
4. Prefer a distinctive macrostructure over a standard hero + three cards + feature grid when the content supports something better.
5. Make typography do real work: deliberate size ratios, line length, weight, tracking, and text density.
6. Use color as a system with a restrained accent strategy, not as ambient decoration.
7. Make components fit the product's character instead of accepting default rounded-card styling everywhere.
8. Preserve accessibility, responsive behavior, state clarity, and interaction affordances.
9. Run the review gates before calling the design finished.

When the user names a reference brand or style, combine this skill with `design-toolkit`; use the reference as a constraint source, then adapt it to the product rather than cloning it.
